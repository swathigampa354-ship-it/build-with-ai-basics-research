# Build With AI: Basics — Hackathon Research

Research and competitive analysis for the Devpost hackathon
[Build With AI: Basics](https://learn-ai-basics.devpost.com/) (deadline Oct 26, 2026, 5:00 pm EDT).

## Contents

- [`research-report.md`](./research-report.md) — full research report: official rules extraction,
  GitHub repository audit (~40 candidates verified via API/source inspection), licence analysis,
  saturation/gap analysis, weighted repo scoring, and three project concepts with one recommendation.
- [`search-logs/`](./search-logs/) — raw GitHub search API result dumps backing the saturation counts.

## Method summary

Read-only verification: GitHub REST API + raw source inspection of every shortlisted repo
(licenses, trees, commits, tests, CI). No repository code was executed. Evidence in the report is
labelled VERIFIED / INFERRED / UNKNOWN.
